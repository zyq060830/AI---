# SafeWalk - AI 夜间安全陪伴系统

## 项目简介

SafeWalk 是一个 AI 驱动的夜间安全路线规划系统，专为女性夜间出行设计。

**核心价值：** 不仅告诉用户"怎么最快到家"，更重要的是"怎么最安心地到家"。

## 用户场景

- 🌙 晚间加班回家的白领女性
- 🏙️ 异地实习/出差的年轻人
- 🎓 大学生夜间出行
- 🌍 陌生城市的游客

## 产品特点

✨ **AI 情绪理解** - 识别用户害怕/不安的心理状态  
🛡️ **安全路线推荐** - 基于摄像头、路灯、人流、便利店等多维度数据  
🤖 **实时 AI 陪伴** - 全程语音/文字指导，让用户不再孤单  
📍 **一键 SOS** - 紧急时刻快速通知亲友和求助  
👥 **好友守护** - 亲友可实时查看用户位置和安全状态  

## 功能演示

### 5 个核心页面
1. **首页** - 用户输入情绪状态和目的地
2. **AI 分析中** - 系统分析用户需求
3. **路线推荐** - 多维度安全评分的路线对比
4. **AI 陪伴中** - 用户出行途中的实时陪伴（核心体验）
5. **安全到家** - 完成反馈，通知亲友
